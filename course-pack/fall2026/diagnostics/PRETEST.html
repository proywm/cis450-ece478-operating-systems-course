CIS 450 / ECE 478 · Fall 2026

Beginning-of-course pre-test: systems foundations

0 points; not graded. Your result does not affect your course grade. This diagnostic helps the instructor identify which prerequisite ideas need review before the operating-systems work begins.

Before you begin

  • Make one honest attempt using only your current knowledge. Do not use an AI assistant, search engine, textbook, notes, or another person’s answers.
  • It is fine to write “I do not know yet.” That answer is more useful than a copied answer.
  • Canvas records your identity and response. Any class-level summary will be reported in aggregate.
  • Show your reasoning where requested. Clear partial reasoning is useful even when the final answer is uncertain.

Questions

  1. Core data structures. Compare a queue, a stack, and a priority queue. For each one, explain where or according to what rule an item is inserted and which item is removed next.

  2. Average memory-access time. A two-level memory system has a faster level with access time 0.1 microseconds and a slower level with access time 1.0 microseconds. The faster level’s hit rate is 95%. Assume a hit costs 0.1 microseconds. Assume a miss costs 1.0 microseconds to access the slower level plus 0.1 microseconds for the subsequent faster-level access; ignore all other transfer cost. Calculate the average access time and show the weighted expression you used.

  3. Queue trace. An initially empty FIFO queue Q executes these operations in order: enqueue(a), enqueue(b), enqueue(c), and x = dequeue(). What value is stored in x? Briefly explain.

  4. Number representation. Write decimal 211 in:

    1. 8-bit binary; and
    2. 2-digit hexadecimal.

    Show one conversion step or consistency check.

  5. Direct memory access. In your own words, explain what direct memory access (DMA) allows a device controller to do, identify one benefit, and state whether the CPU must remain idle during the entire transfer.

  6. Interrupts and subroutine calls. Give two differences between an interrupt and an ordinary subroutine call. Then name two events that can cause an interrupt, trap, or exception.

  7. Priority-queue reasoning. A job ready queue is stored as an unsorted array. Every job has a distinct numeric priority, and a larger number means higher priority. Write pseudocode for a function that returns the lowest-priority job without changing the array. State the time complexity in terms of the number of jobs and justify it in one sentence.
