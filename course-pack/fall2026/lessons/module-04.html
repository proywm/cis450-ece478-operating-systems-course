Address Spaces, Relocation, and Segmentation

Learning objectives

  • Identify code, data, heap, and stack.
  • Translate addresses with base and bounds.
  • Analyze fragmentation and segmented growth.

  1. Chapter 13: The Abstraction: Address Spaces
    Read for: Code, heap, stack, isolation, and the goals of memory virtualization.
  2. Chapter 14: Interlude: Memory API
    Read for: malloc/free, allocation errors, and memory-management interfaces.
  3. Chapter 15: Mechanism: Address Translation
    Read for: Base-and-bounds translation, protection, and OS/hardware responsibilities.
  4. Chapter 16: Segmentation
    Read for: Segment registers, growth, sharing, and external fragmentation.

An address space is the process-visible arrangement of code, static data, heap, stack, and mapped regions. Virtual addresses must be translated and checked before physical memory is accessed.

Dynamic relocation adds a base to a virtual offset and checks the result against a bound. The hardware performs the fast check; the OS controls base/bounds values during context switches.

Segmentation represents logically different regions with separate bases, limits, and growth directions. It improves flexibility but introduces external fragmentation and placement questions.

Worked base-and-bounds translation: with base 32768 and bound 16384, virtual addresses 0, 128, and 16383 translate to physical addresses 32768, 32896, and 49151. Virtual address 16384 faults because legal offsets are 0 through 16383; the check is strictly less than the bound.

Worked segmentation case: separate code, heap, and stack bases avoid allocating the unused virtual gap between heap and stack. Code base 32 KiB plus offset 100 gives 32868, and heap base 34 KiB plus offset 100 gives 34916; a downward-growing stack uses its own translation rule. Variable-size physical regions save the gap but create external fragmentation.

Readiness questions with explanations

Remember Which region normally grows as dynamic allocation occurs?
  1. Code
  2. Heap
  3. Program counter
  4. Page table register

Answer: B. malloc-family allocation typically expands or maps heap storage.

Apply With base 4000 and bound 500, what happens to virtual address 300?
  1. Fault
  2. Physical 3700
  3. Physical 4300
  4. Physical 4500

Answer: C. 300 is within the 500-byte bound, so translation is base + offset = 4300.

Source: OSTEP Chapter 15: Address Translation

Analyze What is a main cost of variable-sized segmentation?
  1. No protection
  2. External fragmentation
  3. No sharing
  4. Every access causes a disk read

Answer: B. Variable-sized segments leave noncontiguous holes that can make allocation difficult.

Source: OSTEP Chapter 16: Segmentation

Apply Which C memory-management error occurs when code accesses a heap object after passing it to free?
  1. Use-after-free
  2. External fragmentation only
  3. A scheduler convoy
  4. A TLB hit

Hint: Ownership of the allocated object has ended.

Answer: A. After free, the pointer no longer designates storage the program may safely access; reading or writing through it is undefined behavior.

Source: OSTEP Chapter 14: Memory API

Understand Why can stack and heap use separate segments?
  1. They have different logical roles and growth behavior
  2. Segments eliminate all fragmentation
  3. They must share one base
  4. The stack is always on disk

Hint: Think about region-specific translation and growth.

Answer: A. Separate bases, bounds, permissions, and growth directions fit distinct regions.

Source: OSTEP Chapter 16: Segmentation

Apply Base is 8000 and bound is 1000. What happens to virtual address 1200?
  1. Physical 9200
  2. Physical 6800
  3. Protection fault
  4. TLB hit

Hint: Check validity before adding the base.

Answer: C. The offset 1200 exceeds the 1000-byte bound, so translation must fault.

Source: OSTEP Chapter 15: Address Translation

Analyze Which memory map is most vulnerable to external fragmentation?
  1. Variable-sized segments allocated among holes
  2. Fixed-size page frames
  3. One register value
  4. A contiguous disk log only

Hint: External fragmentation concerns unusable gaps between allocations.

Answer: A. Variable-size allocation leaves separated free holes even when total free space is adequate.

Source: OSTEP Chapter 16: Segmentation

Evaluate A translation worksheet lists only final physical addresses. What crucial evidence is missing?
  1. Validity/bounds checks and arithmetic
  2. The student name font
  3. CPU fan speed
  4. The directory color

Hint: Choose evidence that distinguishes a valid translation from a lucky guess.

Answer: A. A final number cannot show whether protection was checked or how the mapping was derived.
