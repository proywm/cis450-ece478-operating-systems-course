# Programming 1B preparation: process instrumentation

**Authority:** Planning guide only. Canvas supplies the official program,
kernel fields, expected output, contribution rules, and submission format.

Practice adding one small user program, tracing process creation, and locating
process state in the teaching OS. State the invariant before editing. Make one
change at a time, rebuild from a clean state, and keep a short change log.

Evidence to practice: expected output, actual output, focused code diff, the
kernel location responsible for each observation, and team contributions when
teams are authorized.
