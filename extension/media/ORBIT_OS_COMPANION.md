# Orbit OS companion asset record

`orbit-os-anime.svg` is an original, code-native project illustration created
for the CIS 450 / ECE 478 SystemStudio extension. It does not copy a character,
sprite, or artwork from VS Code Pets or another third-party project.

The assistant is decorative where nearby text already names the action. Its
launch button and tutor controls retain explicit accessible names. CSS motion
stops automatically when the operating system requests reduced motion.
