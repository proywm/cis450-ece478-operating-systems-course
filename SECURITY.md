# Security and privacy

- Learning progress and grade estimates stay in VS Code's local extension
  storage. They are not sent to the instructor, GSI, Canvas, or an AI service.
- The extension never requests a Canvas password or access token.
- Canvas remains authoritative for deadlines, submissions, feedback, and
  official grades.
- The helper is deterministic and offline. It does not transmit student code.
- Container commands run only after the student clicks a command. Review the
  generated `.devcontainer` and `compose.yaml` files before use.
